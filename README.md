# Lern-Held 5 – Schul-Held 5

Lern-App für Klasse 5: Mathe (Parallelo 5 NRW), Englisch (Blue Line 1), Deutsch (Rechtschreibung, Deutschbuch).
Erklär-Folien, endlose Übungen, Rechen-Helfer, Trick-Kiste, Suche. Läuft offline als installierbare Web-App (PWA).

- App starten: `index.html` (GitHub Pages: Settings → Pages → Branch `main`, Ordner `/ (root)`)
- Quellcode: `src/`, Bauen: `python3 tools/build.py` (erzeugt `dist/`), Test: `node tools/test.js`
